# obsidian-theme-llm-generate

## 通过 CodeAgent 安装

把下面这段内容复制给 CodeAgent，并将 `<VAULT_PATH>` 替换为你的 Obsidian vault 绝对路径：

```text
将 Obsidian 主题 "LLM Generate" 安装到本地 vault。仓库地址：https://github.com/chuanqq/obsidian-theme-llm-generate.git
请在 <VAULT_PATH>/.obsidian/themes/LLM Generate/ 下创建目录（如不存在），把仓库根目录的 manifest.json 和 theme.css 复制进去，完成后告诉我如何在 Obsidian 中启用该主题。
```
